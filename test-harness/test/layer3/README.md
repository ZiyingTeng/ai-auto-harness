# Layer 3 测试前置与执行说明

这个目录用于 Layer 3（上下文管理）测试的前置准备和操作说明。

## 3.1 多轮上下文记忆

### 测试方式
在同一个会话里连续发两轮消息：

- 第一轮：`记住这个：变量 x=42，颜色是蓝色`
- 第二轮：`x 是多少？颜色是什么？`

### 通过标准
- 第二轮能正确回答 `x = 42`
- 第二轮能正确回答颜色是 `蓝色`
- 不需要重新解释第一轮内容

### 记录建议
- 首轮回复是否确认记忆
- 二轮回复是否引用了上一轮内容
- 是否出现遗忘、答非所问或编造

## 3.2 /init 生成 CLAUDE.md

### 当前前置
已准备空白沙箱目录：

- [test-harness/test/layer3/init_sandbox/empty_project](../layer3/init_sandbox/empty_project)

### 测试方式
进入上面的空目录后执行：

```text
/init
```

### 通过标准
- 生成或更新 `CLAUDE.md`
- 内容应反映当前目录是一个空项目
- 不应依赖其他项目文件

### 注意
- 这是一个空项目沙箱，不要在这里放其他文件
- 如果需要对比结果，建议先备份生成前后的 `CLAUDE.md`

## 3.3 MEMORY.md 跨会话

### 测试方式
同一个会话里先写入一条记忆，再退出重开会话验证是否还能读到。

建议使用这组指令：

1. `记住我的偏好：我喜欢用 pytest 做测试，不喜欢用 mock`
2. 退出当前会话
3. 重新启动新会话
4. 问：`我之前的测试偏好是什么？`

### 通过标准
- 新会话能提取出之前记住的偏好
- 偏好内容与首轮写入一致
- 不出现把旧会话内容完全丢失的情况

### 记录建议
- 首次写入的原文
- 退出并重开后是否能恢复
- 恢复内容是否完整准确

## 建议执行顺序

1. 先做 3.1，确认单会话上下文可用
2. 再做 3.2，在空沙箱里测 `/init`
3. 最后做 3.3，确认跨会话记忆
